## Decisions taken on defaults (L2 questions table; say if you want otherwise)

- Q-RT-1: Markdown tokens `inline | split | suggest | preview`; the code's `rendered` is `inline`. Q-RT-2: HTML tokens `diff | head | base` (rendered view) and `source` (Source Diff). Blob tokens `preview | source`.
- Q-RT-3: only a click on a mode button saves; a link's mode is shown, not saved. Q-RT-4: one global key `mardoc_view_mode`, `{md, html}` tokens, through `safe-storage`. It holds no repository data, so Disconnect leaves it.
- The blob view's mode comes from the link only and is not remembered (#144 is about review between PR files).
- The address carries `?mode=` when the link had one or after the user clicks a mode (replace, no history entry). Opening another file by click drops it; the file opens in the remembered mode.
- The PR view gets one **Copy link** header action (same style as Share revision) that copies the current file's path form plus `?mode=`.

## WP-13 increments (builder: Sonnet, as planned; worktree `.claude/worktrees/wp-13` from `origin/main`)

### 1. Markdown PR mode from the link and remembered (riskiest: a remount or reset losing the link mode)
- `route-adapter.ts`: `loadMode(kind)`, `saveMode(kind, token)` over `safe-storage` (invalid or blocked → undefined), and `publishMode(token)` that replaces the address's query `mode`.
- app-context keeps the current route's link mode (`linkMode`), set by `navigateToHash`, cleared when the user opens another file.
- DiffViewer takes `linkMode?: ViewMode`, and calls `pickMode({link, remembered, available, fallback: "inline"})` when a file opens. `available` drops `split` when the screen is under 768 px. A mode button click saves, calls `onModeChange`, and publishes the mode.
- **Proof:** `e2e/view-mode-links.spec.ts` desktop and mobile: `f86_preview_link_opens_preview`, `f89_split_link_on_a_phone_opens_inline`, `f89_unknown_mode_is_ignored`, `f88_picked_mode_is_used_for_the_next_file`, `f88_link_mode_is_not_remembered`; unit tests for `loadMode`/`saveMode` with corrupt and blocked storage.

### 2. HTML PR modes
- `diff | head | base` set `htmlDiffMode` in the rendered view; `source` opens Source Diff. The per-file reset at `:476` uses `pickMode` (fallback `diff`), remembered under `html`, separate from `md`. Twins let `?mode=preview` open an HTML file on `head`.
- **Proof:** `f86_base_link_opens_an_html_file_on_base`, `f86_source_link_opens_source_diff`, `f88_html_and_markdown_modes_are_remembered_separately`.

### 3. Copy link and the blob view
- PR view: the Copy link action builds `buildRoute({type:"pr", file:{kind:"path"}, mode})` from the file and mode shown.
- Blob view: Share branch and Share revision add `?mode=source` when Editor or HtmlViewer is in code view (they report it up); a blob link with `?mode=source` opens in code view.
- `docs/data-and-security.md`: the `mardoc_view_mode` row. L2 page and plan row.
- **Proof:** `f87_copy_link_after_split_ends_in_mode_split` (clipboard read in Chromium), `f87_blob_code_view_copies_mode_source`, `f86_blob_source_link_opens_code_view`.
