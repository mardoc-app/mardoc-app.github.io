## Answers to the brief's questions

**(2) Do the proposals solve the issues, keep logic pure, and fit together?**
- **#142:** yes. Path form plus a legacy index, and `file/3` versus `files/3` is unambiguous. It needs L2R-3 (resolve after the manifest).
- **#143:** half. Markdown yes; HTML and the blob form are undefined, and Copy link drops the mode (L2R-4, L2R-5).
- **#144:** yes. The remembered mode is global, a link's mode is never saved, and DiffViewer is keyed by index (`PRDetail.tsx:620-624`), so the initial-mode prop is the right seam.
- **#151:** yes. The model works from the path alone, so the order in which the tree and the file arrive does not matter. The store is injected. L2R-15 and L2R-16 are edge cases.
- **#140:** sorting and jump yes. It misses the counts query (L2R-7).
- **#139:** the rule is wrong (L2R-6). The interpretation (PR approval, not a per-file "done") should be an open question with this default.
- **Purity:** all three proposals keep rules out of React, `window` and storage. `tree-expansion.ts` and `view-mode.ts` take storage and URL values from callers. The fit is weakened only by three parallel layout rules (L2R-11).
- **Deep links:** links-routing and repo-browsing agree. #151 adds no hash format and no hash writes, and reads `selectedFile.path`. links-routing changes the blob form only by an optional `mode` (whose meaning L2R-5 asks to define). repo-browsing's journey still names `hash-router.ts`, which links-routing moves to `routing/route.ts`. That is harmless; update it when the move lands.

**(4) IDs.** The renumbering commit changed only page-local IDs (Q-1 to Q-6 and Q-37 to Q-42 became Q-XX-n; LR-1 to LR-4 and LR-12 to LR-14 became LR-12 to LR-25). Each in-page reference was renamed to the matching row. I compared every renamed reference with the row it names. LR-10 and LR-11 are untouched and still match `check-layout.mjs:175`, `:178`. No global Q-n (Q-11, Q-12, Q-36) is referenced or renamed, and no Q-XX-n clashes with a Q-n elsewhere. Leftovers are in L2R-12.

**(6) Contradictions and how to merge.** Iframe and host messaging: L2R-10 (merge into one protocol module, two adapters, one LR-15). Markdown converter ownership: L2R-13. Pure-module rules: L2R-11. Image loader destination (LR-24 against LR-18): resolved in L2R-10. The embed page's parent and recap: L2R-17. No other contradictions: resilience LR-19 (only `safe-storage` touches `localStorage`) agrees with links-routing's adapter and repo-browsing's injected store, and LR-20 (load generation plus abort) agrees with pr-review Q-PR-1.
